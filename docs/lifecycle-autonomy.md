# Lifecycle Autonomy — React / Symbiosis / Dream

Autonomy index $\mathcal{I}_a$ elevates Fluxa from reactive UI to a living cycle.

## Modes

| Mode | Condition | Behavior |
| --- | --- | --- |
| `react` | `Ia < 0.5`, recent human activity | Normal metabolism + water |
| `symbiosis` | Human active, `Ia ≈ 0.5` | Shared rhythm with pointer |
| `dream` | Idle &gt; 30s, `Ia > 0.8` | Ethereal palette, harmonic affinity, throttled autonomous stub |

## Engine

`FluxaLifecycleEngine` ticks inside the same rAF as homeostasis. Outputs:

- `autonomyIndex` → `u_autonomy` (dream mix + UV warp)
- `affinity` → blended into `u_attraction` while dreaming
- `reportCodeHealth({ hasErrors })` for stress/energy pulses

JSON visceral wire format (`stress_level` / …) is unchanged. Gray-Scott and Obsidian agent loops remain stubs.
